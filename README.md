# Mathematical Foundations of Deep Learning

## 🚀 Live Site
The complete curriculum, including lecture notes, practice sets, and research projects, is available at:
**[https://lowrank.github.io/rtg-mfdl/](https://lowrank.github.io/rtg-mfdl/)**

## 🛠 Local Setup
To run the documentation site locally for development:

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Serve the site**:
   ```bash
   mkdocs serve
   ```
   The site will be available at `http://127.0.0.1:8000`.

## 📁 Structure
- `docs/`: Markdown source files for the curriculum.
- `mkdocs.yml`: Configuration for the Material theme and navigation.
- `requirements.txt`: Necessary Python packages.
