# 07 — Differential Equations in Deep Learning

This module bridges the gap between classical numerical analysis and modern deep learning. We explore how continuous-time dynamical systems, represented by Ordinary, Stochastic, and Partial Differential Equations (ODEs, SDEs, PDEs), provide a powerful framework for modeling complex physical phenomena and generative processes.

**Prerequisite Tier**: Tier 2-3 — Intermediate / Advanced (Requires Multivariable Calculus, Linear Algebra, and basic ODE knowledge)

## 📄 Core Literature

- **Chen, R. T., et al. (2018)**: [Neural Ordinary Differential Equations](https://arxiv.org/abs/1806.07366) - The seminal paper on continuous-depth networks.
- **Ho, J., et al. (2020)**: [Denoising Diffusion Probabilistic Models](https://arxiv.org/abs/2006.11239) - Foundations of modern generative diffusion.
- **Raissi, M., et al. (2019)**: [Physics-informed neural networks](https://maziarraissi.github.io/PINNs/) - Solving PDEs using neural networks.
- **Karniadakis, G. E., et al. (2021)**: [Physics-informed machine learning](https://www.nature.com/articles/s42254-021-00314-5) - A comprehensive review.
